Comienza desde zero.

Necesito construir una aplicación para la gestión de inventario de mi instituto (https://www.sapalomera.cat). Los requerimientos son los siguientes:

Arquitectura:
Python +Django (ultimas versiones)
Base de datos local

Usuarios
Puede haber usuarios locales o usuarios que usen su cuenta de google.

Tipos de usuarios
Hay usuarios de consulta de datos, otros de inserción de datos y otros administradores que pueden hacer todo.

La aplicación tiene que permitir guardar un id único de inventario, una descripción, un tipo de inventario (ordenador,mesa,silla,...) una fecha de compra, fotografias y ubicación (aula,armario,..) y varios campos libres por si se quieres usar para enlazarlo con contabilidad

La aplicación debe de poder generar un numero de etiquetas qr con un nomenclatura definible por el administrador del sistema.Cuando se generan las etiquetas se generan fichas de activo(elemento a inventariar) vacias.

El proceso de dar de alta un nuevo inventario consistiria en que el usuario ha impreso un conjunto de etiquetas qr, coge una la engancha en el elemento a inventariar. A partir de ahi desde la aplicación escanea el codigo qr, y se 
se solicita la foto y  la otra información para completar la ficha.  Si el codigo que se escanea ya existiera se mostraria la fecha del activo.

La aplicación debe tener también una opción para leer un codigo qr, y sacar la ficha del activo.

La aplicación debe tener también las opciones de mantenimiento de tablas auxiliares como aulas, ubicaciones,armarios,tipos de inventario,etc

La aplicación debe tener una gestion de usuarios.

La aplicación debe tener un look&feel moderno y tecnologico y debe de poderse ejecutar también desde un movil.

Necesito más modificaciones. Primero modica la aplicación para que cuando estamos haciendo la ficha del activo, en lugar de pedir subir las fotos las pueda ir tomando desde la misma camara. Puedo añadir todas las que quiera.

Tambien necesito que se pueda configurar desde la aplicación el numero de etiquetas que van por pagina. También necesito que todos los textos que aparecen en la aplicación esten en catalan
